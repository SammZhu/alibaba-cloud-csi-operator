# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

By participating, you are expected to uphold this code. Report unacceptable
behaviour privately to the maintainer (see [OWNERS](OWNERS); for security-sensitive
reports use [SECURITY.md](SECURITY.md)).
